## IDs

Block ID’s like mod:identifier - for example minecraft:oak_stairs

Tags using #. Like \#stairs, \#wooden_stairs, \#mineable/axe [https://minecraft.fandom.com/wiki/Tag](https://minecraft.fandom.com/wiki/Tag)

## State

Block states - like age: 0 , leaves:small, facing:east, half, shape, waterlogged , etc
