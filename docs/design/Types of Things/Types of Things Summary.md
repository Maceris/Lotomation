General grouping of diverse ideas for what will be in the game until we have better organization.

# Blocks

# Fluids

Different types (made of gas, liquid), and measured in ml.

# Energy

Single, official energy system and units. Energy produced and consumed is measured in Joules using a long, which allows for measuring up to about 2.56 petawatt-hours.

Wireless, but connected behind the scenes and maybe visually.

# Items

Exist in inventories, belts, storage.

- Mod ID
- Item ID
- Tags (Not stored in item)
- Extra data - damage, energy, material, etc. Probably JSON?

# Transport

Belts, pipes (fluid and gas), power poles.

# Logic

Factorio style wires and logic gates.

# Recipes

Standardized, editable (like crafttweaker), data driven.

Add and remove functionality, all are shapeless. There are general recipes, and machine-specific recipes.

## Power Sources

Fuel - wood, charcoal, coal, oil - Require a not-easily-renewable resource

Steam - Requires fuel, like coal and water, but might be more renewable

Nuclear - Long term, perhaps dangerous

Renewables - Wind, solar

## In This Game

1. Mining by hand
2. Basic, manually filled, automation
3. Full automation, but manual power resource (steam powered steampunk machines)
4. Full automation, electric machines
5. Higher tier automation, more efficient
6. ???
7. Scifi-tier, teleportation, transmutation, etc.

Machines, belts, power transport, etc. all have multiple tiers.

New processes and recipes are introduced as the game goes on, that add more efficiency but at the cost of more complexity to set up or use.
