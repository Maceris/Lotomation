# Belts

|**Type of belt**|**Examples**|**Status**|
|---|---|---|
|Powered, separate connector|Buildcraft wooden pipes+ engines|Rejected|
|Unpowered, separate connector|Create output belt, GregTech conveyor|Rejected|
|Powered, directly connects||Rejected|
|Unpowered, directly connects|Ender IO conduit, satisfactory belts|Accepted|
|Don’t connect|Factorio inserters|Rejected|
|Machine controls the output, not the belt|IC2 machines, machine-to-machine output|Rejected|

Ender IO conduits don’t have 2 blocks in the same space, unlike GregTech pipe + conveyor, or Extra Utilities 2 pipe + Transfer Node. We prefer 1 block per block, but also don’t like the lack of creativity required by Ender IO conduits that handle all the logistics for you.

# Splitters

There are splitters that split one belt into 1-3, or combine 1-3 belts into 1, like in Satisfactory.

- Splitter that allows 1 filter on one of the 3 outputs
- Filter splitter that allows 1 item on each of the 3 outputs
- Filter splitter that allows for n items per output
