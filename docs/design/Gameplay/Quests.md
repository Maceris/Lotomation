# Definitions

| **Column**          | **Description**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | **Type**    |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- |
| Name                | The title of the quest                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | String      |
| Description         | The text of the quest                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | String      |
| Main                | Whether this is a main quest or a side one                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | Boolean     |
| Tab                 | Which tab in the quest list that this goes on                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | String      |
| Prerequisites       | What quests must be completed before this quest is available                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | String List |
| Prerequisites Logic | Logic for pre-requisites if there are multiple (AND, OR, XOR, etc)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | String      |
| Repeatable          | Whether this quest can be repeated                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | Boolean     |
| Auto Claim          | Whether this quest will automatically be claimed and give rewards, instead of having to be accepted manually                                                                                                                                                                                                                                                                                                                                                                                                                                              | Boolean     |
| Requirements        | What is required to complete the test  <br>  <br>Break Block - Break a specific block  <br>Checkbox - The player just has to click on a checkbox on the quest  <br>Crafting - The player has to craft a specific object  <br>Interact Entity - The player has to interact with a specific kind of entity  <br>Interact Item - The player has to use a specific kind of item  <br>Location - The player has to reach a specific location (position, structure, biome, dimension)  <br>Retrieval - The player has to have a certain item in their inventory | String      |
| Rewards             | What rewards are given for completing a quest  <br>  <br>Choice - The player has to choose between a list of items  <br>Command - Run a command/script  <br>Item - Give the player an item  <br>Recipe - Unlock a recipe                                                                                                                                                                                                                                                                                                                                  | String      |
