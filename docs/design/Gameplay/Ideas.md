# Fresh

- Filter splitter that split by mod, material, type, etc
- Glow baskets made of mushrooms instead of /in addition to torches, as an homage to Pern
- Some kind of hash or UUID for recipes, for use in machines and save files
- Only have bare minimum crafting in inventory, must build workbench for almost anything. Preferably an automated one, albeit simple at first.

# Accepted

- Resources are generated without patches - **need to nail down the mechanics/details**
- Multiple dimensions included in the save file format - Just in case, but not currently encouraged
- Power storage - we will need some kind of storage for power, especially with things like solar power
- biology, plant and animal research, genetic engineering, bacteria colonies
* Magic, magical crystals, rituals
* Magitech / magical bioengineering
* Eldrich, fleshy/dark/glitchy stuff

# Rejected

| **Idea**                                                                                                                                                                                                                                         | **Rejection Reason**                                                                                                                            |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Start with a storage computer. Or get one very early, with various upgrades throughout the game.                                                                                                                                                 | Computers trivialize things like logistics, prevent pretty or clever storage solutions. Would need a lot of work-shopping to be a good idea     |
| Ores spawn on the surface. They can’t be destroyed until later in the game. They don’t run out, ever.                                                                                                                                            | We don’t want to encourage players to expand the factory too much. Keeping it compact and removing the need to expand will limit chunk loading. |
| There are indestructible patches at bedrock level, which are more pure (better yields) but need special machines to mine.                                                                                                                        | We aren’t adding ores                                                                                                                           |
| Only basic ores on the original planets, the player has to go to other planets for more advanced ores. Something like [Planetary Logistics Station](https://dyson-sphere-program.fandom.com/wiki/Planetary_Logistics_Station) for automated I/O. | Don’t want to encourage too much expansion, let alone multiple worlds being loaded or simulated at the same time                                |
| Glass comes from quartz patches, not sand                                                                                                                                                                                                        | No patches, but being derived from sand or quartz is still fair game                                                                            |
